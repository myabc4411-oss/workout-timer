사용법User Guide

💪 이 앱은 무엇인가요? What is this app?

준비운동 → 운동 → 휴식을 정해진 세트 수만큼 반복하고, 마지막에 스트레칭까지 안내해주는 인터벌 운동 타이머예요. 세트마다 운동 종목별 무게·횟수와 메모를 남길 수 있어서, 운동 기록도 함께 관리할 수 있어요.An interval workout timer that cycles Warm-up → Work → Rest for a set number of sets, then guides you through a final stretch. You can log weight/reps per exercise and notes for each set, so it doubles as a workout log.

1. 루틴 설정하기 Set up a routine

  • 루틴 이름 — 저장할 때 구분할 수 있는 이름이에요.Routine Name — a label to tell saved routines apart.
  • 운동 종목 (쉼표로 구분) — 한 세트 안에서 수행하는 종목들을 "풀업, 딥스, 푸쉬업, 스쿼트"처럼 쉼표로 나눠 입력하세요. 휴식 시간에 이 종목별로 기록칸이 자동으로 생겨요.Exercises (comma-separated) — list the exercises you do in one set, e.g. "Pull-ups, Dips, Push-ups, Squats". A log field for each appears automatically during rest.
  • 준비운동 / 운동 시간 / 휴식 시간 / 세트 수 / 스트레칭 — 각 단계별 초 단위 시간과 반복할 세트 수예요. 입력하면 아래 "총 예상 시간"이 바로 계산돼요.Warm-up / Work / Rest / Sets / Stretch — durations in seconds and how many sets to repeat. "Total Time" below updates as you type.

2. 타이머 조작하기 Control the timer

  • ▶ 시작 — 설정한 루틴대로 타이머가 시작돼요. 단계가 바뀔 때마다 소리로 알려줘요.Start — begins the timer per your routine, with a sound cue on every phase change.
  • ⏸ 일시정지 / ▶ 재시작 — 잠깐 멈췄다가 이어서 할 수 있어요.Pause / Resume — pause briefly and pick up where you left off.
  • ■ 정지 — 운동을 중간에 끝내요. 진행 상황을 저장하면 나중에 "지난 기록 보기"에서 이어하기로 중단했던 세트부터 다시 시작할 수 있어요.Stop — ends the workout early. If you save your progress, you can resume from the interrupted set later via Resume in Workout History.

3. 세트 기록 남기기 Log a set

타이머를 시작하면 화면이 꽉 찬 전체화면으로 전환돼요. 세로/가로 어느 방향으로 들어도 자동으로 레이아웃이 맞춰집니다. 휴식 시간이 되면 방금 끝낸 세트의 기록 카드가 자동으로 떠요. 입력한 운동 종목마다 무게(kg)·횟수를 각각 적고, 아래 세트 메모에 컨디션이나 특이사항을 자유롭게 남기면 입력하는 즉시 저장돼요. 마지막 세트는 휴식이 없기 때문에, 운동이 끝나면 타이머가 잠깐 멈추고 기록 카드가 떠요 — 기록을 남기고 ✅ 저장하고 계속하기를 누르면 다음 단계로 넘어갑니다. 화면 위쪽의 ⌄ 최소화를 누르면 언제든 전체화면을 벗어날 수 있고, 오른쪽 아래 버튼으로 다시 들어갈 수 있어요.Starting the timer switches to a fullscreen view that adapts to portrait or landscape automatically. When rest starts, the log card for the set you just finished appears automatically — everything saves as you type. Since the last set has no rest, the timer pauses there and waits for you to log the set and tap Save & Continue. Tap Minimize at the top anytime to step out of fullscreen, and the floating button brings you back in.

4. 루틴 저장 / 불러오기 Save / Load a routine

💾 루틴 저장으로 자주 쓰는 설정을 저장해두고, 📂 불러오기로 언제든 다시 불러올 수 있어요.Use Save Routine to store settings you use often, and Load to bring them back anytime.

5. 지난 기록 히스토리 보기 View workout history

📖 지난 기록 보기를 누르면 완료(또는 중간에 저장한) 운동 기록이 최신순으로 나와요. 항목을 탭하면 세트별 상세 기록이 펼쳐지고, 날짜를 선택해서 특정 날짜 기록만 찾아볼 수도 있어요. 필요 없는 기록은 ✕ 버튼으로 지울 수 있어요. 중간에 정지한 기록에는 ▶ 이어하기 버튼이 있어서 멈췄던 세트부터 다시 시작할 수 있고, ✏️ 수정 버튼으로는 이미 남긴 무게·횟수·메모를 나중에 고칠 수 있어요.Tap View Past Records to see finished (or manually saved) workouts, newest first. Tap an entry to expand its set-by-set details, or filter by date to find a specific day. Remove records you no longer need with the ✕ button. A record that was stopped early shows a Resume button to pick up from the interrupted set, and Edit lets you correct weight/reps/notes you already logged.

🔊 타이머 소리 바꾸기 Change the timer sound

타이머 조작 아래 "타이머 소리"에서 기본 비프음 외에 복싱 종·휘슬·차임벨 중 골라 쓸 수 있어요. 미리듣기 버튼으로 소리를 확인해보세요.Under Timer Controls, pick from the default beep, boxing bell, whistle, or chime. Use the Preview button to hear it first.

📌 기록은 이 기기에만 저장돼요 Records are stored on this device

모든 루틴·기록은 이 폰(브라우저)에만 로컬로 저장돼요. 앱을 지우거나 다른 기기로 바꾸면 기록이 함께 사라지니, 소중한 기록은 "운동 기록 복사하기"로 가끔 백업해두거나 구글 드라이브 백업을 사용하는 걸 추천드려요.All routines/records are stored locally on this phone/browser only. Uninstalling the app or switching devices erases them, so back up important records with "Copy Log" occasionally, or use the Google Drive backup feature.

브라우저 메뉴에서 "홈 화면에 추가"를 누르면 아이콘이 생겨서 일반 앱처럼 바로 열 수 있어요.Tap "Add to Home Screen" in your browser menu to get an icon you can open like a regular app.
